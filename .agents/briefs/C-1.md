# C-1 · cadcraft: Croatian letters and en-dash in the stroke font, MTEXT word gap

Branch `agents/C-1`, PR to `zokito/cadcraft` `main` only. Model: follow the repo's own
CONTRIBUTING/AGENTS docs and code style. File:line references come from an analysis of commit
1d7ea87; `main` has moved since, so verify each location before editing.

## Problem
A TEXT/MTEXT "Dnevna soba – staza od rublja (čćžšđ)" is stored correctly as UTF-8 in DXF, but
PNG and SVG export draw boxes for every non-ASCII char and MTEXT word gaps look collapsed.

## Causes (verified by analysis)
- C1: default style font "CADCraft Stroke" (crates/fonts/src/lib.rs ~21, ~160) resolves to
  `TextFont::Stroke`; no per-char fallback.
- C2: crates/fonts/src/stroke.rs ~11-111 covers ASCII + `° ± Ø ø ⌀` only (`_ => return None`).
- C3: crates/fonts/src/lib.rs ~106-110 draws a 4-unit box for an unknown glyph (the tofu).
- C4: crates/fonts/src/mtext.rs ~393 (seg_width) and ~510 measure words with `line_width`,
  which subtracts the trailing GAP, and the space with `text_width(" ")`: word gap 0.4h in MTEXT
  vs ≈0.93h in TEXT (`layout_line`).

## Do
1. F1: add stroke glyphs for Č Ć Ž Š Đ č ć ž š đ (U+010C U+0106 U+017D U+0160 U+0110 and
   lowercase) and `–` U+2013 (e.g. `'–' => (4.0, "0f4f")`), plus `’ „ “ ”` if trivial.
   Diacritics above capitals exceed the cap row (i=6): extend the grid upward (e.g. rows j,k)
   in the decoder and in `glyph_points_stay_in_grid`, without changing existing glyph shapes.
2. F2: make the MTEXT word gap equal the TEXT word gap: measure a word as the sum of its
   advances (keep the trailing GAP), or measure the space with `char_advance(' ')`.
   Update `wraps_to_width` / `wrap_respects_runs_and_width` expectations only where the new
   metric legitimately moves wrap points; say which in the PR body.
3. Do not add font assets, system-font fallback or new crates (F3 is out of scope).
